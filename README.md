# ListaFácil

SPA de lista de compras feita com **React + Vite + React Router**.

## Propósito
Ajudar o usuário a montar sua lista de compras e marcar o que já foi comprado, navegando entre seções sem recarregar a página.

## Por que React?
- **Componentização:** `Navbar` e `ItemCard` são componentes reutilizáveis.
- **Estado e eventos:** `useState` atualiza a tela a cada ação do usuário.
- **SPA:** o React Router troca de seção sem recarregar a página.

## Seções
- **Início:** resumo de itens que ainda faltam.
- **Minha lista:** adicionar item com quantidade, marcar como comprado e remover.
- **Contato:** formulário simples.

## Como executar
```bash
npm install
npm run dev
```
